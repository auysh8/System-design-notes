<div class="note-section">
    <div class="section-title">
        <span class="title-badge" style="background: var(--pastel-blue);">1</span>
        Transport Layer Overview: Reliability vs. Speed
    </div>

    <p>The <mark class="hl-blue">Transport Layer</mark> is responsible for end-to-end communication, packet delivery, flow control, and error recovery between host applications across a network.</p>

    <div class="card-grid">
        <GoodNotesCard title="🛡️ TCP: Reliable but Slower" accent="blue">
            <p><strong>Connection-oriented protocol</strong> that guarantees 100% data delivery in exact sequence with built-in error checking and retransmissions at the cost of slight latency overhead.</p>
        </GoodNotesCard>

        <GoodNotesCard title="⚡ UDP: Fast but Unreliable" accent="pink">
            <p><strong>Connectionless, lightweight protocol</strong> that transmits packets immediately without establishing a handshake or waiting for acknowledgments, optimizing purely for minimum latency.</p>
        </GoodNotesCard>
    </div>
</div>

{/* SECTION 2: TCP DEEP DIVE */}
<div class="note-section">
    <div class="section-title">
        <span class="title-badge" style="background: var(--pastel-green);">2</span>
        TCP (Transmission Control Protocol)
    </div>

    <StickyNote type="sky" title="🔒 Key Characteristics of TCP:">
        <ul style="font-size: 0.95rem; margin: 0.25rem 0 0 1.2rem; line-height: 1.7;">
            <li><strong>Guaranteed Packet Delivery:</strong> Every sent packet must be confirmed with an acknowledgment (ACK).</li>
            <li><strong>Connection-Based:</strong> Requires a formal <strong>3-Way Handshake</strong> before any payload data transfers.</li>
            <li><strong>Ordered Packets:</strong> Packets contain sequence numbers; out-of-order packets are reassembled correctly by the receiver.</li>
            <li><strong>Error Checking & Retransmission:</strong> Corrupted or dropped packets trigger timeouts and automatic re-sends.</li>
        </ul>
    </StickyNote>

    <div style="margin-top: 1.25rem;">
        <GoodNotesCard title="💼 Best Suitable For:" accent="green">
            <p style="font-size:0.95rem;">
                Critical workloads where <strong>zero data loss</strong> is required: 
                <strong>Payment Gateways, Banking Transactions, User Authentication APIs, File Transfers (FTP/SFTP), Emails (SMTP/IMAP), and Web Pages (HTTP/HTTPS)</strong>.
            </p>
        </GoodNotesCard>
    </div>
</div>

{/* SECTION 3: UDP DEEP DIVE */}
<div class="note-section">
    <div class="section-title">
        <span class="title-badge" style="background: var(--pastel-yellow);">3</span>
        UDP (User Datagram Protocol)
    </div>

    <StickyNote type="yellow" title="⚡ Key Characteristics of UDP:">
        <ul style="font-size: 0.95rem; margin: 0.25rem 0 0 1.2rem; line-height: 1.7;">
            <li><strong>No Delivery Guarantee:</strong> Fire-and-forget datagram delivery with no acknowledgment mechanism.</li>
            <li><strong>Connectionless:</strong> No handshake setup or teardown state stored on sender or receiver.</li>
            <li><strong>Faster Transmission:</strong> Zero waiting time for connection establishment or lost packet recovery.</li>
            <li><strong>Minimal Protocol Overhead:</strong> 8-byte lightweight header compared to TCP's 20–60 byte header.</li>
        </ul>
    </StickyNote>

    <div style="margin-top: 1.25rem;">
        <GoodNotesCard title="🎮 Best Suitable For:" accent="purple">
            <p style="font-size:0.95rem;">
                Time-sensitive applications where <strong>speed matters more than occasional dropped packets</strong>: 
                <strong>Live Video Calling (WebRTC / Zoom), Live Video Streaming (Twitch / YouTube Live), Multiplayer Online Gaming, Voice over IP (VoIP), and DNS Queries</strong>.
            </p>
        </GoodNotesCard>
    </div>
</div>
