    <div class="card-grid">
        <StickyNote type="yellow" title="📈 Vertical Scaling (Scale Up)">
            <p style="font-size: 0.9rem;">Adding resources (<mark class="hl-yellow">CPU, RAM, SSDs</mark>) to the same single server node.</p>
            <ul style="font-size:0.8rem; margin: 0.5rem 0 0 1rem;">
                <li><strong>Pros:</strong> Simple setup; no code alterations required.</li>
                <li><strong>Cons:</strong> Hardware capacity ceiling & SPOF risk.</li>
            </ul>
        </StickyNote>

        <StickyNote type="mint" title="🌐 Horizontal Scaling (Scale Out)">
            <p style="font-size: 0.9rem;">Adding more server instances and distributing incoming traffic using a <mark class="hl-green">Load Balancer</mark>.</p>
            <ul style="font-size:0.8rem; margin: 0.5rem 0 0 1rem;">
                <li><strong>Pros:</strong> Infinite horizontal growth & zero downtime availability.</li>
                <li><strong>Cons:</strong> Complex state sync & network management.</li>
            </ul>
        </StickyNote>
    </div>
