                <td><span class="protocol-tag" style="background: var(--pastel-purple); font-weight: 800;">PATCH</span></td>
                <td><strong>Update (Partial)</strong></td>
                <td><code>PATCH /api/v1/products/123</code></td>
                <td style="text-align: center;">
                    <span style="background: var(--pastel-pink); color: var(--text-main); font-weight: 800; font-size: 0.78rem; padding: 0.2rem 0.6rem; border-radius: 12px; border: 1px solid var(--pastel-pink-dark); display: inline-block;">❌ Unsafe</span>
                </td>
                <td style="text-align: center;">
                    <span style="background: var(--pastel-pink); color: var(--text-main); font-weight: 800; font-size: 0.78rem; padding: 0.2rem 0.6rem; border-radius: 12px; border: 1px solid var(--pastel-pink-dark); display: inline-block;">❌ Non-Idempotent*</span>
                </td>
            </tr>
            <tr>
                <td><span class="protocol-tag" style="background: var(--pastel-pink); font-weight: 800;">DELETE</span></td>
                <td><strong>Delete / Destroy</strong></td>
                <td><code>DELETE /api/v1/products/123</code></td>
                <td style="text-align: center;">
                    <span style="background: var(--pastel-pink); color: var(--text-main); font-weight: 800; font-size: 0.78rem; padding: 0.2rem 0.6rem; border-radius: 12px; border: 1px solid var(--pastel-pink-dark); display: inline-block;">❌ Unsafe</span>
                </td>
                <td style="text-align: center;">
                    <span style="background: var(--pastel-green); color: var(--text-main); font-weight: 800; font-size: 0.78rem; padding: 0.2rem 0.6rem; border-radius: 12px; border: 1px solid var(--pastel-green-dark); display: inline-block;">✅ Idempotent</span>
                </td>
            </tr>
        </tbody>
    </table>

    <div class="card-grid" style="margin-top: 1.25rem;">
        <StickyNote type="yellow" title="🔒 Definition: Safe Methods">
            <p style="font-size:0.9rem; line-height: 1.6;">
                <strong>Safe Methods</strong> are strictly read-only and guarantee <em>zero server-side state mutation</em>. Clients can pre-fetch, cache, and execute them unconditionally (e.g., <code>GET</code>, <code>HEAD</code>, <code>OPTIONS</code>).
            </p>
        </StickyNote>

        <StickyNote type="sky" title="🔁 Definition: Idempotent Methods">
            <p style="font-size:0.9rem; line-height: 1.6;">
                <strong>Idempotent Methods</strong> produce the <em>exact same server state</em> whether executed 1 time or repeated 1,000 times ($f(f(x)) = f(x)$). Crucial for safe automatic network retries during network timeouts (e.g., <code>PUT</code>, <code>DELETE</code>, <code>GET</code>).
            </p>
        </StickyNote>
    </div>
</div>

<div class="note-section">
    <div class="section-title">
        <span class="title-badge" style="background: var(--pastel-orange);">6</span>
        API Design Best Practices: Anti-Patterns vs. REST Standards
    </div>

    <StickyNote type="sky" title="📋 4 Golden Principles of RESTful API Architecture:">
        <ol style="font-size: 0.95rem; padding-left: 1.2rem; line-height: 1.7; margin: 0.25rem 0 0 0;">
            <li><strong>Use Plural Nouns for Resources:</strong> Never embed verbs in URIs (use <code>/users</code>, <code>/orders</code>).</li>
            <li><strong>Model Hierarchical Parentage Intuitively:</strong> Reflect ownership via clean paths (<code>/products/123/reviews</code>).</li>
            <li><strong>Expose Expressive Query Modifiers:</strong> Provide filtering, sorting, and pagination on all collection routes.</li>
            <li><strong>Explicit API Versioning:</strong> Always prefix paths with version identifiers (<code>/api/v1/...</code>) to ensure backward compatibility.</li>
        </ol>
    </StickyNote>
