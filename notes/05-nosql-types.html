Non-Relational (NoSQL) Classifications

Document, Wide-Column, Graph & Key-Value DBs

📄 Document Stores

Stores data in JSON/BSON structures allowing rich nested attributes in a single record.

MongoDB CouchDB

📊 Wide-Column Stores

Organizes data in dynamic column families optimized for high write performance.

Cassandra CosmosDB

🕸️ Graph Databases

Stores nodes and relationships as edges for querying interconnected networks.

Neo4j Amazon Neptune

🔑 Key-Value Stores

KeyValue pair mappings for sub-millisecond lookups and caching layers.

Redis Memcached

📝 Summary Matrix: SQL vs NoSQL

Feature Relational (SQL) Non-Relational (NoSQL)
Data Structure Rigid, well-structured tabular schema Flexible, dynamic schema-less formats
Consistency Strong consistency & strict ACID guarantees Eventual consistency (BASE) models
Latency Optimized for joins; higher write overhead Super-low latency for fast write throughput
Scaling Primary scaling via Vertical (Scale Up) Native Horizontal scaling (Scale Out)
